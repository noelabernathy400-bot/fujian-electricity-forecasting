# Decision Log

## 2026-05-06

### 决定：从新疆方法准备转向福建真实数据实证

原因：当前已获得福建省较完整的日度用电数据，而新疆细分行业月度数据尚未到位。为了让研究从“方法准备”进入“实证可运行”，先以福建为对象开展预测、结构和传导分析。

### 决定：不删除、不移动根目录原始数据

根目录新增的两份数据保留不动。项目只复制副本到：

`Projects/InnovationProjects/福建用电量预测与产业因果推断研究/Sources/原始数据/`

所有脚本只读项目内副本，派生数据写入 `Data/processed/`。

### 决定：先做本机可复现实证，不启用服务器

当前数据规模约 160 MB 级别，本机 Python 足以完成清洗、EDA、预测基线和第一轮时序传导。只有大规模 PCMCI/转移熵/bootstrap 或深度学习大量调参时再考虑服务器。

### 决定：因果表述先限制在 Level 1

第一轮 Granger、VAR、预测增强只写成“时序领先证据”或“预测贡献”，不写成强结构因果。若后续加入明确政策事件、对照组和反事实设计，再提升证据等级。

### 决定：预测部分同时保留单步回测和 30 日递推回测

原因：单步回测适合“每天更新真实历史数据”的运营场景，30 日递推回测适合“站在某一天预测未来一段时间”的研究场景。两者误差不可直接混同。当前全省合计单步 MAPE 约 1.87%，30 日递推多起点 MAPE 约 5.49%。

### 决定：Granger 边必须经过 FDR 和滚动窗口稳健性筛选

原因：行业两两检验数量很多，若只看 p 值会产生偶然显著。第二轮已经补充 FDR 校正和 4 个时间窗口稳健性，稳定边作为后续产业解释和因果识别候选集合。

### 决定：把 Granger 候选变量加入预测模型作为“因果辅助预测”检查

原因：如果某条 Granger 边不仅显著，还能改善目标预测，更值得后续研究；如果不改善，也必须保留失败结果。当前加入候选变量对 `制造业` 和 `工业` 有改善，对 `合计`、`商业用电` 等没有改善。

### 决定：用 NASA POWER 做第一版公开天气变量补充

原因：负荷预测中天气是关键外部变量；公开 NASA POWER Daily Point API 不需要密钥，适合先做可复现诊断实验。本轮按福建 9 个地市中心点抓取日度气象变量，并按 2023-2025 年地市用电份额加权成全省天气。

边界：本轮天气实验使用历史实际天气，不能直接等同真实未来预测。正式未来预测必须使用天气预报或天气情景。

### 决定：将官方节假日和调休日编码为可复现日历特征

原因：春节、国庆、中秋、劳动节和调休日会显著改变日度用电模式，而且节假日安排在预测未来时是已知信息。本轮手工编码 2023-2026 年节假日和调休日，并生成 `calendar_cn_holidays_2023_2026.csv`。

边界：节假日日期来自官方通知或政府转载通知；正式论文引用前仍应以中国政府网或国务院办公厅原文为最终引用口径。

### 决定：全省合计预测主线优先转向直接多步预测

原因：递推预测会把前一步误差继续喂给后续预测，30 日整体 MAPE 约 5.49%；直接多步预测为每个 horizon 单独训练模型，加入行业类别滞后、天气和节假日后整体 MAPE 约 3.40%，第 30 天 MAPE 约 3.55%。

边界：当前直接多步天气变量仍使用历史实际天气作为诊断；真实未来预测需要天气预报或天气情景。

### 决定：长假是预测误差的重点薄弱区

原因：长假误差分解显示公共假日 MAPE 约 5.22%，国庆中秋 MAPE 约 5.99%，明显高于非公共假日约 3.18%。这说明即使加入节假日变量，长假冲击仍未完全被模型捕捉。

后续方向：对国庆中秋和春节等长假构造节前、节中、节后分段变量，必要时建立专门长假模型。

### 决定：普通 Granger 稳定边需要条件复检

原因：普通 Granger 可能受到共同经济周期或用电总量变化影响。条件 Granger 在控制 `合计`、`工业`、`制造业`、`大工业电量`、`非普工业`、`居民生活`、`商业用电` 等共同变量滞后后，40 条稳定候选边中 14 条仍通过 FDR 0.05。

边界：这仍不是强因果识别，只能写成“控制部分共同变量后的额外预测贡献”。

### 决定：直接多步预测扩展到重点变量和地市

原因：只做全省合计不足以解释行业与区域差异。本轮结果显示大工业、工业、制造业 1-30 日直接多步 MAPE 约 3.77%-3.89%，居民生活约 7.25%；地市中龙岩、三明、漳州更稳，莆田、宁德更难。

边界：地市和行业直接多步结果仍是预测性能证据，不解释为因果。

### 决定：长假位置特征显著改善假日预测

原因：加入节前、节中、节后和节中第几天等分段特征后，全省合计直接多步整体 MAPE 从 3.40% 降到 3.06%，公共假日 MAPE 从 5.22% 降到 2.62%，国庆中秋 MAPE 从 5.99% 降到 2.96%。

边界：当前只对全省合计验证，后续应扩展到居民生活、莆田、宁德等高误差对象。

### 决定：VARX 天气节假日控制后传导证据必须降级

原因：对普通 Granger 稳定性前 80 条边做 VARX 风格复检，加入共同用电变量、天气和节假日控制后，没有任何边通过 FDR 0.05。这说明先前普通 Granger/条件 Granger 边可能受到共同冲击、外部变量或参数压力影响。

写作边界：当前传导网络只能作为候选线索，不能作为强因果结论；论文中必须保留这一步负结果。

### 决定：将长假分段扩展到高误差对象

原因：只证明全省合计能被长假分段改善还不够，预测研究需要检查难预测对象是否也受益。本轮扩展到 `居民生活`、`宁德`、`莆田`，结果显示三者整体 MAPE 均下降：居民生活从 7.25% 降至 6.69%，宁德从 6.09% 降至 5.70%，莆田从 7.22% 降至 6.84%。其中宁德公共假日 MAPE 从 8.10% 降至 4.37%，说明长假位置效应是其误差的重要来源。

边界：这是预测特征工程证据，不是节假日因果效应估计。

### 决定：单独建立证据等级与结论降级表

原因：当前传导分析同时存在普通 Granger、滚动稳定性、条件 Granger 和 VARX 负结果，若不统一证据等级，论文容易在措辞上不自觉夸大因果。新增 `Notes/证据等级与结论降级表-2026-05-07.md` 作为写作约束。

写作边界：论文主结论优先强调“可解释短期预测 + 行业结构描述 + 时序传导候选发现”，不写成“产业因果网络已经被证明”。

### 决定：结构分析必须包含动态维度

原因：静态占比只能说明“谁大”，不能解释“什么时候高、谁波动大、增长来自哪里”。本轮新增季节性指数、日度波动性和地市增长贡献。地市增长贡献优先使用 9 个地市口径，因为地市能严格加总到全省合计。

边界：`工业`、`制造业`、`大工业电量` 等重点变量之间存在包含关系，不能把它们的增量直接相加。重点变量同比只能作为自身变化描述，不能作为严格加总分解。
