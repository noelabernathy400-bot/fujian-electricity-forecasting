# 福建用电量预测与产业因果推断研究

## 项目定位

本项目是原“新疆电量预测与产业因果推断研究”方法框架的真实数据实证版本。由于当前已获得福建省日度用电数据，本项目先以福建为研究对象，跑通预测、行业结构和时序传导分析。

## 核心问题

1. 福建全省和各地市未来用电量能否被稳定预测？
2. 不同用电类别和行业用电量的结构、季节性、波动性如何？
3. 哪些行业或用电类别的历史变化对总用电量、工业用电量或重点行业具有前置预测贡献？
4. 这些关系能支持到什么证据等级：描述相关、预测贡献、时序传导，还是更强因果？

- `Sources/原始数据/福建全省用电量统计20230101至20260109.xlsx`

原始根目录文件不删除、不移动；项目内只使用副本。

## 方法继承

继承新疆项目的方法库：

- 预测基线与特征工程
- ADF、协整、ECM/VECM
- Granger、VAR、IRF
- CCM、PCMCI、转移熵
- 行业结构和投入产出解释
- 证据等级与稳健性检查

## 研究边界

福建项目可以证明方法框架可落地，但不能直接代表新疆产业结构。所有结论必须写明福建数据口径、时间范围、行业分类和证据等级。
