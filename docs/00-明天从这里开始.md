## 2. 当前研究主线

不再只做普通预测，也不急着恢复旧的 Granger/因果叙述。当前先做：

1. CSV 长表和变量字典。
2. 全社会用电总量闭合验证。
3. 制造业 31 类闭合验证。
4. 制造业行业分组。
5. 结构转型信号预验证。
6. 如果信号成立，再进入前置信号网络和解释型预测。

- 第二阶段“总量结构分解”已完成，并写入主文档。
- 第三阶段“制造业结构转型信号预验证”已完成，并写入主文档。
- 第四阶段“前置信号行业识别”的初筛版已完成，并写入主文档。
- 第四阶段加强版前置信号检验已完成，并写入主文档。
- 主文档图表显示问题已处理：流程图和第二阶段结果图均使用 PNG，相对路径已检查无断链。
- 第二阶段核心结论：第二产业和制造业是福建全社会用电的主体，但第三产业和居民生活也贡献了相当一部分新增用电，因此后续不能用制造业单独解释全社会总量。
- 第三阶段核心结论：制造业内部存在温和结构优化信号，但传统高耗能与材料行业仍是最大存量和最大新增来源；不能写成“先进制造取代传统行业”或“产业升级已完成”。
- 第四阶段初筛核心结论：结构转型指标 T/R 比制造业总量更容易出现前置信号；但目前只是候选信号，不是 Granger，也不是因果。
- 第四阶段加强版核心结论：制造业总量没有较稳健单行业前置信号；结构转型指标 T/R 有更强预测领先信息。创新重心应放在“结构转型指标 + 前置信号 + 解释型预测”，不是强行做完整因果网络。
